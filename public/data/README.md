# U.S. college directory

`us-colleges.json` is a compact snapshot of four-year and two-year U.S.
postsecondary institutions from the U.S. Department of Education's NCES/IPEDS
ArcGIS institution layer.

- Snapshot date: July 28, 2026
- Included IPEDS levels: `ICLEVEL` 1 and 2
- Stored fields: institution name, city, and state/territory abbreviation
- Source: <https://nces.ed.gov/arcgis/rest/services/IPEDS/IPEDS/MapServer/0>

The file is served locally by Quicky Resume. No search text or resume data is
sent to NCES while a user types.
